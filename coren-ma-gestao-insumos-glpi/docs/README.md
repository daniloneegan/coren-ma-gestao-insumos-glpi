# Documentação do projeto

Este diretório reúne a especificação inicial do protótipo acadêmico de gestão de insumos do COREN-MA. O escopo não pressupõe acesso a ambientes, dados ou APIs reais do Conselho ou do GLPI.

- [Requisitos](requisitos.md): funcionalidades, regras e critérios de aceite.
- [Riscos](riscos.md): ameaças, limitações e ações recomendadas.
- [Protótipo](prototipo.md): telas, fluxos, estados e decisões de interface.

## Premissas

1. O sistema controla itens de consumo em um banco próprio; integração com GLPI é uma possibilidade futura a validar.
2. Usuário, permissões, localizações e processo de reposição precisam ser confirmados junto aos responsáveis.
3. Os dados usados em demonstrações devem ser fictícios ou anonimizados.
4. Este material é uma especificação acadêmica, não uma autorização de implantação.
